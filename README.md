# Glow Up Skin Centre

Open this folder in VS Code, then run:

```sh
npm install
npm run dev
```

The local address shown by Vite opens the preview. `npm run build` creates the deployable `dist` folder. A Gemini key is not needed to view or build this website.

The hero slides left between Dr. M. D. Khalid and Dr. Suhail Navi. Doctor and treatment visuals are embedded in the source for a self-contained GitHub build. The gallery component remains available in source but is not rendered in the current site.

For appointment enquiries, deploy this project on Netlify using the included `netlify.toml`; the form is registered in `index.html`. Test an enquiry on your Netlify site and configure its form notifications before giving the link to patients. The local preview cannot submit requests.
